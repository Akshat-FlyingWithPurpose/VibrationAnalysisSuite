# Vibration Analysis Suite

Desktop application for loading, cropping, and analysing vibration data from a 4-IMU logging module.

---

## Setup

### 1. Clone the repository

```bash
git clone https://github.com/your-org/VibrationAnalysis.git
cd VibrationAnalysis
```

### 2. Install & run (one-time)

**Windows:**

```bat
install.bat
```

That's it. After the first install, launch the app anytime with:

```bat
run.bat
```

**macOS / Linux:**

```bash
pip install -r requirements.txt
python main.py
```
